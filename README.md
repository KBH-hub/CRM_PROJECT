# 🌱 프로젝트명
병원 고객 관리 시스템 개발 프로젝트

# 📌 서비스 소개 
**의료기관 CRM 기반 고객 관리 시스템 구축**
- 의료진 전용 화면
- 의료진 근무 스케줄 확인 
- 접수부서 전용 웹 어플리케이션
- 환자 정보 관리, 예약 관리, 의료진 근무 관리

# 🛠 기술 스택
| 구분 | 기술 스택 |
|---|---|
| **WAS** | Apache Tomcat 8 |
| **Front** | JavaScript, jQuery, Ajax |
| **Back** | Java, Servlet, MyBatis, Maven, JUnit 4, JSP, Gson |
| **Database** | OracleDB |
| **형상관리** | Git, GitHub |
| **Tooling** | Eclipse, ExERD, Figma, Notion, draw.io |
